A deterministic one-line status update from a lost sock, in pure stdlib Python: no network, no randomness, no dependencies; the same bytes every run.

> Day 6 inside a guitar. The acoustics are amazing, the gigs are nightly, and I finally found my sole purpose.

108 characters — under the 120-character limit. The sock has ended up somewhere it should not be (inside a guitar), made a new life there (nightly gigs), and the punchline is a pun only a sock can make: *sole* purpose. No dryer, no washing machine, no missing pair — the obvious sock material is dodged on purpose.

## Run it

```sh
python3 main.py
```

This writes the status update to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): a single line plus a trailing newline.
